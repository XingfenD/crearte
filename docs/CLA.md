# 贡献者许可协议（CLA）

本协议（"协议"）由您（"贡献者"）与 crearte 项目作者（"作者"）就您向本项目提交的贡献（"贡献"）达成。向本项目提交 Pull Request、补丁或其他形式的贡献，即表示您同意本协议全部条款；如不同意，请勿提交。

## 1. 版权许可

您保留对贡献的版权。您授予作者一项永久、全球范围、非独占、免版税、不可撤销的版权许可，允许作者复制、修改、分发、公开展示、再许可（包括以 [AGPL-3.0-only](https://www.gnu.org/licenses/agpl-3.0.html) 之外的其他条款，如商业授权）及以其他方式使用您的贡献，无论以源代码还是目标代码形式。

## 2. 专利许可

您授予作者一项永久、全球范围、非独占、免版税、不可撤销的专利许可，允许作者制造、使用、销售、许诺销售、进口及以其他方式转移您的贡献，但仅限于您拥有或控制的、被您的贡献必然侵犯的专利权利要求。

## 3. 声明

您声明：(a) 每项贡献均为您的原创作品，或您已获得提交所需的全部权利与授权；(b) 您的贡献不包含第三方保密信息，也不包含与本项目许可不兼容的第三方许可内容；(c) 如适用，您已获得雇主或所属机构对提交贡献的必要授权。

## 4. 无义务

作者没有义务使用、合并或分发您的贡献，也不对贡献的使用承担任何担保或责任。

## 5. 适用范围

本协议适用于您向本项目提交的全部内容，包括代码、数据（如 `src/games/` 下的游戏条目）、文档与设计稿。
