## 站内提交

### 1. 注册并登录

在[注册页](/register)创建账号（邮箱 + 昵称 + 密码，密码 10–128 个字符）。登录后进入[我的提交](/submit)。

### 2. 新建提交，选择提交类型

| 类型 | 用途 |
| --- | --- |
| 新作品 | 首次收录一个作品 |
| 新版本 | 给已收录的**站内运行**作品上传新版本文件 |
| 元数据更新 | 修改已收录作品的介绍信息（名称、描述、标签等） |

### 3. 填写基本信息

| 字段 | 说明 |
| --- | --- |
| 展示名称 | 站内展示的标题（≤ 60 字），必填 |
| 名称 | 小写字母、数字或连字符（1–64 字符，首尾非连字符），用于作品链接 `/games/<名称>`，**收录后不可改**。填好展示名称后会自动生成（英文标题），可手动修改；中文标题无法自动生成，需要自己起一个英文名 |
| 作品原始链接 | 作品在原发布地的 https 链接，必填 |
| 作者名 / 作者链接 | 作者或团队名必填，链接可选 |
| 描述 | 一句话简介（≤ 140 字），必填 |
| 玩法简介 | 可选，详情页展示的 Markdown 长介绍 |
| 时长 / 类型 / 标签 | 预计游玩时长区间；类型单选；标签最多 8 个 |
| 封面 | 可选，png / jpeg / webp，≤ 5MB |

### 4. 选择运行方式

- **外链作品**：玩家点击后经过中间页跳转到你的链接。
- **站内运行**：上传 zip 包，玩家在站内直接游玩。zip 要求、版本号、运行权限开关等见[站内运行作品指南](/docs/virtual-works)。

### 5. 草稿与审核

- **存草稿**：随时保存，之后可继续编辑，也可以直接删除。
- **提交审核**：进入审核队列。审核中不能编辑，但可以**撤回**（撤回后该提交被删除，需重新创建）。
- **已通过**：作品上架目录。之后仍可发起「元数据更新」或「新版本」提交来修改。
- **已拒绝**：会附带审核意见，按意见修改后**重新提交**即可。

上传文件有频率限制，触发限流时页面会提示等待时间，稍后重试即可。

## GitHub PR 静态收录

如果不想将您的作品交给我们托管，可以向我们的开源项目 [crearte](https://github.com/XingfenD/crearte.git) 提交PR，或者发送邮件到 [xingfend@outlook.com](xingfend@outlook.com) 介绍您的作品。我们将在审核后将您的作品页面合入开源crearte的主分支中。

1. 在仓库 `src/games/` 目录新增 `<id>.json`，`id` 只能包含小写字母、数字与连字符，且与文件名一致
2. 本地运行校验：`cd src && npm install && npm run validate:data`
3. 提交 PR，CI 会自动校验数据格式

字段与站内提交一致（`name` 即展示名称、`id` 即名称/链接名），另需 `addedAt`（收录日期 `YYYY-MM-DD`）；完整约束见 `src/schema/game.schema.json`。
