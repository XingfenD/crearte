## 什么是站内运行作品

把作品打包成 zip 上传到本站，玩家无需跳转、直接在站内游玩。上传的文件由服务端**加密存储**，分发时解密安装到玩家浏览器的本地缓存，之后**离线也能玩**。

## bundle 要求

- 格式：zip，≤ 100MB
- 内容：**纯静态**文件（HTML / JS / CSS / 图片 / 音频等），不能包含需要服务端执行的代码
- 入口：需指定一个入口文件（如 `index.html`），路径为 zip 内相对路径
- 依赖：请自包含所有资源，不要引用需要登录或有防盗链的外部资源

上传成功后会显示文件大小与 sha256 摘要，可据此确认传对了包。

## 版本号与更新

- 版本号需匹配 `^[a-z0-9][a-z0-9._-]{0,63}$`（如 `1`、`v1`、`1.0.0`）
- 发布新版本：在[我的提交](/submit)对已收录作品发起「新版本」提交，上传新 zip
- 玩家侧行为：新版本通过审核后，已安装的玩家再次打开时会收到更新；更新失败时**保留旧版本**继续可玩
- 注意：提交表单里修改「名称」或「版本号」会使本次已上传的 bundle 作废，需要重新上传

## 运行权限开关

站内运行作品默认在严格的内容安全策略（CSP）下执行，以下能力默认关闭，仅当作品代码确需时在提交表单勾选：

| 开关 | 什么时候需要 |
| --- | --- |
| 允许 eval / new Function | Alpine.js、Vue 完整版等需要在运行时编译表达式字符串的框架 |
| 允许内联 `<script>` | 单文件 HTML 作品。能改成外部 `.js` 文件则更安全，建议优先改文件 |

审核时会按需保留或收紧这些开关；已发布的作品，管理员也可以在后台调整，保存后立即生效。

## 存档与数据隔离

每个站内运行作品在**独立的子域名**下运行，localStorage / IndexedDB 等存储与其他作品和主站完全隔离——作品之间不会互相读到数据。

作品详情页会显示该作品当前占用的存档大小，玩家可以一键**清除存档**（谨慎：不可恢复）。

## 游玩体验

- 游玩区域支持**全屏**（控制条上的全屏按钮）
- 首次打开需要下载并安装 bundle，页面会显示下载进度；之后从本地缓存加载，速度更快且离线可用
