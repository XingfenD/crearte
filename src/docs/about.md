## 托管您的创意

crearte（创艺）收集**纯静态的网页作品**：打开网页即用、无需安装、无需服务端。游戏、测评、小工具都可以，HTML5 / WebGL / Canvas 实现均欢迎。

## 收录形式

- **外链作品**：作品托管在您自己的服务器上，本站收录链接与介绍。
- **站内运行作品**：将您的作品作品打包成 zip 上传到本站，服务端加密存储，玩家直接在站内游玩，无需跳转到外部网站。详见[站内运行作品指南](/docs/virtual-works)。
