## 这是什么

crearte（创艺）收集**纯静态的网页作品**：打开网页即用、无需安装、无需服务端。游戏、测评、小工具都可以，HTML5 / WebGL / Canvas 实现均欢迎。

## 收录的两类作品

- **外链作品**：作品托管在您自己的服务器上，本站收录链接与介绍。
- **站内运行作品**：将您的作品作品打包成 zip 上传到本站，服务端加密存储，玩家直接在站内游玩，无需跳转到外部网站。详见[站内运行作品指南](/docs/virtual-works)。

## 如何参与

1. [注册一个账号](/register)
2. 进入[我的提交](/submit)，点「新建提交」，按[提交作品指南](/docs/contribute)填写
3. 通过审核后即会出现在[作品目录](/games)

如果不放心将您的作品交给我们托管，您还可以向我们的开源项目[crearte](https://github.com/XingfenD/crearte.git)提交PR，或者发送邮件到[xingfend@outlook.com](xingfend@outlook.com)介绍您的作品。我们将在审核后将您的作品页面合入开源crearte的主分支中。
