## 这是什么

crearte（创艺）收集**纯静态的网页作品**：打开网页即用、无需安装、无需服务端。游戏、测评、小工具都可以，HTML5 / WebGL / Canvas 实现均欢迎。

## 收录的两类作品

- **外链作品**：作品托管在你自己的服务器上，本站收录链接与介绍。访问时经过一个中间页确认后跳转，链接长期可用是收录前提。
- **站内运行作品**：你把作品打包成 zip 上传到本站，服务端加密存储，玩家直接在站内游玩，无需跳转到外部网站。详见[站内运行作品指南](/docs/virtual-works)。

两类作品都要求**纯前端**：不收录需要下载客户端、注册第三方账号才能使用、或依赖自己服务端的作品。

## 如何参与

1. [注册一个账号](/register)
2. 进入[我的提交](/submit)，点「新建提交」，按[提交作品指南](/docs/contribute)填写
3. 通过审核后即会出现在[作品目录](/games)

维护者也接受通过 GitHub PR 直接提交静态收录数据，见提交指南的次要途径一节。
